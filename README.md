# كلين هاوس - Clean House SA 🧹

موقع Landing Page احترافي لشركة كلين هاوس للتنظيف الاحترافي في المملكة العربية السعودية.

## 🚀 المميزات

- **Next.js 14** App Router + TypeScript
- **Tailwind CSS** - تصميم احترافي RTL
- **Framer Motion** - تأثيرات حركية سلسة
- **SEO محسّن** - Meta Tags + JSON-LD + Sitemap + robots.txt
- **Responsive** - يعمل على جميع الأجهزة
- **RTL كامل** - دعم اللغة العربية
- **خط Cairo** - خط عربي احترافي
